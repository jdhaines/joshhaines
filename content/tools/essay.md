Essay is a web and mobile application that provides a structured writing environment, designed to help writers of all levels to find a topic of interest, organize their thoughts, improve their ideas, and communicate more effectively.

I found the Essay app while learning more about writing from videos from Jordan
Peterson. His son, Julian Peterson, is the founder of Essay. You can see more
about that part of my writing journey in my [first article](/content/my-writing-journey#jordan-peterson-as-a-writing-champion) on it.

I've found the four-step framework that Essay uses to be very helpful in learning
to write better. If you want to learn more about the framework for strong writing
that they use, you can read the [Writing Guide](https://essay.app/guide/).
