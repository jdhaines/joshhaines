# Security Policy

This is a personal publishing/portfolio site (JoshHaines.com) -- there's no
sensitive user data, authentication, or payment processing. Still, reports
of real vulnerabilities are welcome.

## Reporting a vulnerability

Please use GitHub's [private vulnerability reporting](https://github.com/jdhaines/joshhainesnext/security/advisories/new)
for this repository rather than opening a public issue. If that's not
available, reach out privately to the repository owner.

Include:

- a description of the vulnerability and its potential impact
- steps to reproduce, or a minimal proof of concept
- the affected page/route or dependency, if known

There's no bug bounty program -- this is a best-effort response on a
personal project, not a commercial service.
